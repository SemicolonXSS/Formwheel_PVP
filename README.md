# ⚔️ Formwheel PVP

Formwheel의 실시간 아레나 대전 프로젝트입니다.

[🎮 플레이](https://semicolonxss.github.io/Formwheel_PVP/) · [🛠️ 스튜디오](https://semicolonxss.github.io/Formwheel_PVP/studio.html) · [🏠 Hub](https://semicolonxss.github.io/Formwheel/) · [💬 피드백](https://semicolonxss.github.io/Formwheel/feedback.html)

## 현재 지원 기능

- 무기 10종, 특수 능력 8종, 기본 맵 5종
- 이동속도 및 체력에 포인트를 배분하는 10P 로드아웃
- 난이도 1~10의 싱글 플레이 AI
- Firebase 방 코드 기반 온라인 1대1 **베타**
- 맵·무기 커스텀 제작 및 로컬 저장
- PC 및 모바일 터치 조작

## 플레이 방법

1. 무기와 특수 능력, 맵을 고르고 속도 포인트를 배분합니다.
2. AI와 대전할 경우 **경기 시작하기**를 누릅니다.
3. 친구와 대전할 경우 한 명이 **방 만들기**를 누른 뒤 6자리 코드를 공유하고, 다른 사람이 **방 참가**를 선택합니다.
4. PC: **WASD/방향키** 이동, **Space/클릭** 공격, **E** 특수 능력. 모바일: 화면 아래 방향키·공격·특수 버튼.

## 개발·테스트 참고

- 온라인 모드는 베타로 네트워크 연결, 로그인/게스트 인증 및 Firebase 보안 규칙 상태에 영향을 받습니다.
- 커스텀 제작물은 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있습니다.
- AI 플레이와 온라인 플레이의 일부 기능 및 밸런스는 서로 다를 수 있습니다.
- 최신 UI와 코드 변경 사항은 GitHub Pages 반영 후 확인해 주세요.

이 프로젝트는 Formwheel 생태계의 일부입니다.
